
# Task Board – Angular Practice Project

A personal practice project built to refresh and deepen my Angular and TypeScript skills alongside my professional software development work.

## Features

- Add new tasks using Reactive Forms
- Form validation
- Mark tasks as completed or pending
- Filter completed tasks using Angular Signals
- Task counter
- Navigation between Tasks and About pages
- Responsive layout

## Technologies

- Angular
- TypeScript
- HTML
- CSS

## Run locally

```bash
npm install
ng serve
```

Open http://localhost:4200

## What I Learned

This project helped me practice Angular components, services,
dependency injection, routing, reactive forms, signals,
event binding and dynamic CSS classes.

## Notes

This is a learning project. Tasks are stored in memory and
reset when the application is reloaded.
